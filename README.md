# 暨大午夜巡航 五境解謎

以暨南大學為背景的繁體中文單人解謎遊戲。場景配置、星空觀測室與封鎖事件均為虛構，採深夜懸疑風格，無鬼怪或突然驚嚇。

## 遊戲特色

- 五個連續場景：教室、圖書館、電腦教室、實驗室、星空觀測室。
- 難度逐步增加：觀察排序、索引比對、編碼轉換、邏輯排除、跨關整合。
- 五關共用三十分鐘，轉場不重設時間，每次答錯扣三十秒。
- 線索筆記保存已調查的內容與通行徽記，最後一關需要整合先前徽記。
- 每關三層提示；通關後呈現實際耗時、剩餘時間、答錯懲罰與提示次數。
- 單一 HTML 檔，無外部套件、無登入、無資料上傳。

## 使用方式

直接以現代瀏覽器開啟 `index.html`，或前往公開遊戲：

https://luproject-maker.github.io/midnight-archive/

## GitHub Pages

在儲存庫的 Settings > Pages 中，選擇 Deploy from a branch，分支選 main、目錄選 / (root)，儲存後等待部署完成。

## 技術

HTML、CSS 與原生 JavaScript。支援桌面及手機版面。遊戲紀錄僅存在目前分頁，重新整理會清除進度。
